# QUIET shop
1. Create a GitHub repo, upload everything in this folder (index.html, admin.html, products.json, logo.png).
2. Settings > Pages > Deploy from branch > main / root.
3. Open `/admin.html` on your site. Set your WhatsApp number (country code + number, no +).
4. For publishing from the admin: GitHub > Settings > Developer settings > Fine-grained tokens > only your repo > Contents: Read and write.
